# Voice Chat Mode (Coming in v0.4)

Two-way voice conversation is planned for a future release. In this mode:
- You speak, Claude listens
- Claude responds with synthesized speech
- Natural conversational flow with voice activity detection
- Voice selection: accent, gender, speed

## Current Status

This feature requires the Claudia Chatterley companion app with TTS (text-to-speech) support, which is planned for v0.4.

## What's available now

**Voice-to-text input** is available today via `/voice-input`:
1. Install: `pip install claudia-chatterley`
2. Run: `claudia`
3. Click the floating 🎤 mic and speak
4. Your words appear as text — review, edit, press Enter

This already gives you the 3x speed advantage of speaking over typing.
